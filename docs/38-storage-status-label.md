# Nhãn trạng thái lưu kho chờ thanh lý

- Hai mã dữ liệu `LUU_KHO_THANH_LY` và `LUU_KHO_CHO_THANH_LY` cùng hiển thị là **Lưu kho chờ thanh lý**.
- Ánh xạ dùng chung áp dụng cho dashboard, danh sách, hồ sơ thiết bị và dữ liệu xuất báo cáo.
- Mã cũ vẫn được giữ để không làm thay đổi hoặc mất liên kết dữ liệu hiện có.
